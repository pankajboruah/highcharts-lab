# highcharts-lab

A small collection of Highcharts + React interaction patterns — legend
isolate/multiselect, cross-chart crosshair sync, drag-to-zoom with range refetch,
sparklines, stacked columns, and a category breakdown with a live threshold filter.

**Live demo:** https://highcharts-lab.vercel.app

## What's actually being shown

| Section                                  | Highcharts technique                                                                                                                                                                                |
| ---------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Legend isolate + shift-multiselect       | Custom `legendItemClick` override — plain click isolates a series, shift+click builds a multiselect, visibility is managed manually via `series.setVisible()` instead of Highcharts' default toggle |
| Synced crosshair across charts           | Walks Highcharts' own `Highcharts.charts` global registry on point `mouseOver`/`mouseOut` to sync hover/crosshair state across independent chart instances, with no shared parent state             |
| Zoomable chart with range refetch        | `chart.events.selection` drives a custom React-rendered "Reset zoom" button (native one hidden) and triggers a refetch of a higher-resolution slice for the selected range                          |
| Sparklines in a KPI grid                 | Minimal inline `area` charts — no axes/legend/credits — with a gradient fill and a custom tooltip `positioner`                                                                                      |
| Stacked column with vertical legend      | Same shared legend hook as the line chart, applied to a `stacking: 'normal'` column chart with a vertical right-hand legend                                                                         |
| Resource breakdown with threshold filter | Fixed named-category palette (not the general categorical order) plus a live-adjustable minimum-total filter that drops negligible series entirely                                                  |

## Architecture

- **One shared legend hook** (`src/components/charts/useChartLegend.ts`) implements
  the isolate/multiselect behavior once; every chart type consumes it rather than
  each redefining the same click logic.
- **One shared theme** (`src/components/charts/theme.ts`) sets fonts, the
  categorical palette (validated for CVD-safety), and legend styling globally via
  `Highcharts.setOptions()`, instead of every chart component duplicating its own
  styling.
- **Crosshair sync is a module-level utility, not React Context**
  (`useChartCrosshairSync.ts`) — chart instances are imperative objects outside
  React's tree, and hover events fire at high frequency, so direct calls into
  sibling chart instances via `Highcharts.charts` are the right tool.
- **Mock API + fallback**: a small Express server (`server/`) exposes `/api/*`
  endpoints for local dev. The same route-handler functions
  (`server/handlers/*.ts`) are re-used, unmodified, by the Vercel serverless
  functions in `api/*.ts` — so local dev and production never diverge in
  behavior. The client (`src/lib/apiClient.ts`) fetches with a timeout and falls
  back to bundled static JSON fixtures (`src/lib/mockData/`, pre-generated by
  `scripts/generate-mock-data.mjs` from the same deterministic generators in
  `shared/dataGenerators.ts`) on any failure.

### "Simulate server down" toggle

The header switch is a genuine test of the fallback path, not a fake label. When
enabled, `fetchWithFallback()` short-circuits to the bundled fallback data
_before_ attempting the network call — the same branch a real timeout or network
error would hit, just without waiting out a real timeout. Every chart section
shows a "Live data" / "Offline / cached data" badge driven by which branch
actually ran.

## Local setup

```bash
npm install
npm run dev
```

This runs the Vite dev server and the Express mock server concurrently
(`npm run dev:client` + `npm run dev:server`). Vite proxies `/api/*` to the
Express server in dev.

To run just the mock server and hit it directly:

```bash
npm run dev:server
curl "http://localhost:5174/api/line-series?dataset=latency"
```

## Deployment

Deployed on Vercel — the static build serves from `dist/`, and `/api/*` is
served by the serverless functions in `api/`. No environment variables are
required; all data is generated/mocked, nothing calls a real external API.

## Tech stack

React, TypeScript, Vite, Tailwind CSS, shadcn/ui, Highcharts +
highcharts-react-official, Express (local dev API), Vercel serverless functions
(production API).
